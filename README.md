# Plan-de-Acopio-Kos-ipata-2026---ENACO-S.A.-VBA-
Este sistema automatizado en VBA para Microsoft Excel está diseñado para optimizar el procesamiento, conversión y análisis del Plan de Acopio Kosñipata 2026. Permite gestionar la data cruda de los productores, estandarizar las unidades de medida (de kilos a arrobas),  etc.
